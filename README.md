# Emmanuel Vargas — Portfolio

English-language portfolio for systems integration, software engineering and automation opportunities. Plain HTML, CSS and JavaScript; no build step or framework required.

## Preview

Open `index.html` directly, or run `python -m http.server 8000` and visit `http://localhost:8000`. Fonts use Google Fonts with system fallbacks. All content remains available without JavaScript.

## GitHub Pages

Keep `index.html`, `style.css`, `script.js` and the favicon at the publishing root. Asset paths are relative and support `https://emmanuel-vargas.github.io/portafolio/`. Preserve the repository's existing Pages publishing source when committing and pushing reviewed changes.

## Content maintenance

- Edit visible content directly in `index.html`. The old `projects.json` is retained as an archive of earlier personal projects and is no longer loaded at runtime.
- LinkedIn uses the profile URL supplied in Emmanuel's resume.
- The Download CV button links to `Emmanuel_Vargas_Public_Resume.pdf`, a public version with general experience and capabilities. Keep employer-specific system names and implementation details out of public resumes.
- Add verified courses inside the Certifications & Professional Development article. Do not invent credentials.
- Present general capabilities under "Solutions I Can Build" and personal repositories under "Personal Projects". Do not describe identifiable internal projects. Do not add internal endpoints, credentials, production data or proprietary source code.
- Existing GitHub project links and email were retained. The former Java chatbot demo pointed to the React CRUD app; that incorrect association was removed. Older hosted demos are omitted in favor of their source repositories.
